External Website Embed Demo

See FormCraft Running On Any External Web Page

This static mock client website demonstrates how the FormCraft chatbot widget seamlessly embeds and floats on any customer website with a single script tag.

👉 Look at the bottom-right corner of your screen! Click the floating button to open the conversational form chatbot.

Embedded Script Tag in <head> / <body>:

<script src="/embed.js" data-form-id="AUTO_DETECT" defer></script>

Parameters like data-color and data-position can also be customized directly in the script tag.
